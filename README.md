# Named Entity Recognition for Architecture (NAER)

> [!IMPORTANT]
> **This repository is archived.** NAER is now part of the ARDoCo monorepo:
> [ardoco/ardoco › `core/naer`](https://github.com/ardoco/ardoco/tree/main/core/naer).
> Its full history was merged into the monorepo; please open issues and pull requests there.

NAER is a Java library for identifying named entities (e.g., architectural components) in textual Software Architecture
Documentation (SAD) using Large Language Models (LLMs).

## Maven coordinates

New releases are published from the monorepo:

```xml

<dependency>
	<groupId>io.github.ardoco.core</groupId>
	<artifactId>naer</artifactId>
	<version><!-- ARDoCo version --></version>
</dependency>
```

The last standalone release is `io.github.ardoco:named-architecture-entity-recognition:2.1.0`.
It remains available on Maven Central but will not receive updates.
